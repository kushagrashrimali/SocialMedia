# inbox

Put the files for each new reel or post here, one folder per job (for example `inbox/2026-10-20-diwali-reel/`): reference videos, ElevenLabs audio, reference screenshots or PDFs, and photos. Then point Claude Code at them with `@inbox/...`.

Everything in this folder except this README is ignored by git, so reference videos and raw audio stay on your computer. See `SETUP.md`, Part B.
