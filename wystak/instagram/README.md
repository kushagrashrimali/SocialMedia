# Instagram

| Folder | What is in it |
|---|---|
| `carousels/launch/` | Launch post for cafés: 5 slides |
| `carousels/grocery/` | Post for grocery stores: 5 slides |
| `carousels/salon/` | Post for salons: 5 slides |
| `carousels/launch-v1/` | Older phone-mockup launch carousel (8 slides) |
| `single-posts/` | Single-image posts (none yet) |
| `reels/finals/` | Delivered reel MP4s |
| `reels/scripts/` | Reel voiceover scripts |

Each carousel folder holds the final `slides/*.png` (1080×1350), `copy.md` (slide copy, caption, cover alt text) and the `build.py` that remakes the slides.
